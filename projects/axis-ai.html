Overview

AXIS AI is a cross-disciplinary AI platform that converts multilevel course materials into interactive 3D game-based learning experiences. The project combines course modules, interactive activities, AI-generated learning support, assessment, and backend progress tracking.

Design Focus

The project examines how educational content can be reorganized as an interactive experience while retaining clear learning objectives, assessment points, and usable feedback for learners and instructors.

My Role

  • Collaborate with faculty advisor Prof. Ann Cai on platform and course-module development.
  • Build, upload, and test psychology-, education-, and game-design-related modules.
  • Create 3D environments, visual assets, and tutorial videos.
  • Work with pre- and post-learning assessments, interactive activities, AI-generated summaries, and backend analytics.

Project Support

The project helped secure Northeastern University’s PEAK Fellowship and supported an ongoing NEA Grants for Arts Projects application.

Next Steps

Future portfolio updates can add interface captures, 3D environment images, course-flow diagrams, and evidence from formal testing as those materials become available.
